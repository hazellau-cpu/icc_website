# Info-2 Library Exports

These files are cleaned exports of the library sheets in `Info-2.xlsx`. The five James student/lesson sheets are kept separately in `exports/james-workbook-template/`.

## Short programme IDs

Use `programme_id` from `programme-keys.csv` as the stable key:

- `AIK-L1-O`, `AIK-L2-O`, `AIK-L3-O`, `AIK-L4-O` for AIKIRO original levels
- `AIK-L1-A`, `AIK-L2-A`, `AIK-L3-A` for AIKIRO additional levels
- `ROB-L1`, `ROB-L3`, `ROB-L4`, `ROB-L5` for ROBOKIT
- `UAR-L2` for UARO
- `CM-P1` for CodeMonkey
- `CS1` to `CS5` for CodeCombat

Use `programme_name` when displaying the full programme label. Do not join records by the long programme text.
